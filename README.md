# PC Rebuild Project | Computer Hardware & System Fundamentals

This project focuses on rebuilding a desktop computer from the ground up to develop a deeper understanding of computer hardware, system architecture, and the purpose of individual components.

Throughout this project, I explore the functionality and importance of essential PC components, including the CPU, GPU, motherboard, RAM, storage devices, power supply, and cooling systems. I document the assembly process, examine how each component works, and learn how hardware compatibility impacts overall system performance, reliability, and stability.

**Project Objectives:**
- Identify major PC components and understand their individual functions.
- Learn how hardware components communicate and work together.
- Understand hardware compatibility, installation, and configuration.
- Develop hands-on experience with PC assembly and troubleshooting.
- Explore how hardware knowledge supports cybersecurity, system maintenance, and performance.

**Key Takeaway:**

This project demonstrates my ability to understand computer hardware beyond the software level, strengthening my technical foundation and providing practical knowledge that can be applied to IT support, system administration, and cybersecurity.
